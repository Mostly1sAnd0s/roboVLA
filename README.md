# roboVLA

This project fine-tunes **OpenVLA-7B** (a 7.5B vision-language-action model). It is the capstone for a high-school advanced-robotics class. Up to **12 individual students** each drive their own mecanum-base rover. Each student trains and serves QLoRA adapters through a **web-based training console** on the campus LAN.
